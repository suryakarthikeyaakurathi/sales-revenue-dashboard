# Sales & Revenue Analysis Dashboard

This project was created using Power BI to analyze sales and revenue performance using the Superstore dataset.

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Sales by Category
- Profit Analysis
- Region-wise Sales Analysis
- Revenue Trend Analysis
- Interactive Filters/Slicers

## Tools Used
- Power BI
- Superstore Dataset

## Business Insights
- Technology category generated the highest sales.
- West region contributed the highest revenue.
- Furniture category showed lower profit margins.
- Sales trends varied across years.
